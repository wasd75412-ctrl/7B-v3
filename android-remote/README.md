# 7B 控制台

這個 Android App 讓 P4 六鍵藍牙遙控器控制 7B 羽球社比分。

## P4 六鍵遙控器

同一套對應適用於每一台 Android 手機，不需要重新學習：

- 編號 1：A 隊加 1 分
- 編號 2：B 隊加 1 分
- 編號 3：使用 1 顆球
- 編號 4：加回 1 顆球
- 編號 5：比賽正式開始
- 編號 6：撤銷上一分

## 首次使用

1. 安裝並開啟 App。
2. 點「前往開啟按鍵權限」。
3. 在 Android 設定中選擇「7B 控制台按鍵」並開啟允許。
4. 回到 App，連接球局並登入管理員。

## 錄影計分模式

登入球局後，點「比分轉播錄影」。App 會先保存目前房號、管理員權限與比賽規則，再開啟內建相機。相機會從球局即時讀取目前兩隊球員與比分，以兩列式轉播記分板顯示在左上角，並直接寫進影片。影片直接錄進 `Movies/7B羽球`；按「暫停」可暫停錄影，暫停時段不計入 YouTube 時間軸；按「保存並繼續」會結束目前檔案並立即開始下一段，按「結束」會保存後離開。保存的檔案只會在離開錄影畫面後、連上非個人熱點的 Wi-Fi 時上傳 YouTube。錄影期間按鍵存取服務仍直接寫入同一份即時比分，不依賴背景中的網頁，因此疊圖、其他手機與 iPad 會一起更新，也不會調整音量或中斷錄影。

按鍵存取服務只攔截支援的遙控器按鍵，不讀取畫面內容。一般模式只有 App 顯示在前景時才會轉為計分；錄影計分模式則會在相機位於前景時繼續接收，直到返回 App 關閉此模式。

App 使用和主網站相同的房號、管理員登入與 Firebase 即時資料，所以 Android 手機和 iPad 會同步比分；若背景同步失敗，相機畫面上會以短訊息提示原因。

## 本機建置

使用 Android Studio 內附的 JDK：

```powershell
.\gradlew.bat testDebugUnitTest assembleDebug
```

正式簽署資訊只存放在本機或 GitHub Actions Secrets；`keystore.properties` 和 `signing/` 不會加入 Git。
